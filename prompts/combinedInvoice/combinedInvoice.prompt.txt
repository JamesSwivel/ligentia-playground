<invoiceType>

## Standard Type
Most standard invoices have common layout with features:
- single invoice number
- single invoice date
- A list of line items
- Each line item has item code, QTY, unit price, total amount, etc.
- Some line item may associate with PO number or PI number
- total invoice QTY and total amount

## Combined Type
Some manufacturers/suppliers issue a combined layout of invoice, e.g. some China suppliers.  
It has features different from the standard invoice layout:
- A single doc with combined invoices
- It has a list of PI numbers, e.g. PI-0001, PI-0002, etc
- It has a list of invoice numbers that the number format looks similar to PI list, e.g.
  - The list may look like: CI-0001, CI-0002, etc (using PO base numbers)  OR
  - The list is exactly the same as PI list. In that case, invoice number equals to the PI number.
- The line items are broken down by either PI or invoice number
- Thus, each line item associate not just item code, QTY, unit code, total amount, etc, but also
  invoice number, PI number, PO number
- As it combined multiple invoices into single doc, it has grand combined invoice QTY and total.

Infer from the doc return:
'standard': if the doc is a standard invoice type
'combined': if the doc is a combined invoice type
'': if doc is not an invoice
