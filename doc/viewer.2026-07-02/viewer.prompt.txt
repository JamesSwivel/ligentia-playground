### Overview
- Build a vanilla HTML/JavaScript web viewer
- Light | Dark | System theme (default is system)
- user preference remembered in localStorage, e.g. selected theme
- Support doc type to view: invoice | packing list | doc classification | raw JSON
- For raw JSON display, it should use Monaco library


### Functions
## File upload and 
- The first page is upload area, accepts only JSON file
- auto detect doc type, if the key exists
  - result.jsonData.invoiceDate -> invoice doc type
  - result.jsonData.packingListDate -> packing list doc type
  - result.jsonData.classificationGroups array -> doc classification
  - unknown type -> JSON doc type

## Viewer
- After upload, display the content according to doc type
- For known types, the view should always display data within result.jsonData
- For unknow type, the viewer will display raw JSON 
- Most view contains header and detail items data.  
- If the data has detail items, it should display like a table, and the rows has alternating colors for easier viewing
- If table is displayed, it has basic functions
  - export icon: export as CSV
  - sorting (simple): it allow a single column sorting toggles: ascending/descending/original order. 
    - For ascending/descending, it has a small badge to indicate which column is being sorted. 
    - For the original order, no badge is needed.
  - sorting (advanced): it allow a multiple column sorting, and each column is allowed to toggle: ascending/descending/original order. 
    - for example, advanced users can sort item columns: 'code' (ascending), 'amount' (descending)
  - filtering: it allows user to select single/multiple column, enter the corresponding values, and filter the rows to display
  - sorting reset: to reset the sorting to the original order, but keep filter if previously selected
  - filtering reset: to reset the filtering to the original data, but keep sorting if previously selected
  - reset all: reset both sorting and filtering
